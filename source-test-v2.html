Relay source/model live test v2

29 model/source combinations across 12 providers. Every model carries its own result tag from the last live run (see legend below) — 7 confirmed, 14 limit hit, 7 cors, and 1 timeout. The source-level confirmed/new badge on each group header means something different — whether that source was already known-good before this round of testing — from the per-model tag, which reflects what actually happened when it was run. Pruning policy: a row stays if it's limit/cors/timeout, since none of those prove the model or endpoint is actually wrong, just that it didn't answer this time; a "confirmed" tag also isn't erased by a later limit/cors/timeout result on the same row, since a model that's demonstrably worked once doesn't stop being proof of that just because one later run got throttled — the live Status/Detail columns still show exactly what happened on the most recent run regardless. A row is removed only for a genuine "this doesn't work at all" signal: unrecognized/retired model id, or a hard requirement for a key/login/payment despite being marketed as anonymous. Removed so far, across every round: OVH's Llama-3.1-8B-Instruct and Qwen3-32B (both 404 model_not_found — the latter had been rate-limited, not gone, in an earlier round, so this is a live retirement), three of AI Horde's four models (406 "Model None not known!"), Pollinations text's mistral (404 "Model not found: mistral" on their legacy endpoint), all of PaxSenix (401 key_required despite being marketed "unauthenticated"), all of VLM Run (403 "sign in to use the Completions API" despite a documented guest cap), and all of Puter.js (requires login in practice despite a documented Anonymous tier).
